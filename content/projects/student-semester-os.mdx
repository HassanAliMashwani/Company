## 01 — The Problem

University students manage assignment deadlines, lecture notes, exam schedules, and GPA calculation across fragmented note apps and spreadsheets. Existing student templates were static and lacked automated grade calculation.

## 02 — The Approach

Created a unified workspace OS engineered specifically for university academic terms:

1. **Course Hub**: Centralized syllabus details, office hours, and assignment weight breakdowns.
2. **Dynamic GPA Calculator**: Calculated real-time projected GPA based on weighted assignment scores.
3. **Deadlines Kanban**: Time-aware task board grouping assignments by urgency and course credit weight.

## 03 — The Interface

Distraction-free dark mode dashboard featuring intuitive drag-and-drop course cards and progress indicators.

## 04 — The Build

Next.js 14 App Router, Supabase Database & Auth, Zustand state management, and Tailwind CSS.

> *"Zustand optimistic UI updates provided instant offline task reordering without waiting for Supabase roundtrips."*

## 05 — The Result

Adopted by over 800+ active university student users during the 2024 academic semester rollout.
