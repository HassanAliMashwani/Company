## 01 — The Problem

Users needed a simpler, real-time way to discover and interact with nearby proximity events and local social spaces without navigating through bloated feeds or slow multi-step menus. Existing location applications suffered from heavy latency, intrusive ad banners, and clumsy map rendering on mobile browsers.

## 02 — The Approach

We designed the product from the ground up focusing on rapid spatial discovery. The process followed a lean iterative execution pipeline:

1. **User Flow & Spatial Wireframes**: Mapped high-frequency user actions to single-tap interactions.
2. **Visual System & Map Layering**: Developed custom vector map styling tuned for contrast in both dark and outdoor environments.
3. **Interactive Prototype**: Built high-fidelity Framer Motion micro-interactions to test tap response times.
4. **Full Stack Engine**: Implemented real-time geo-query triggers backed by Firebase spatial listeners.

## 03 — The Interface

The interface prioritizes immediate spatial awareness. The view transitions smoothly between an immersive map layer and crisp event details drawer:

- **Desktop View**: Dual-pane workspace with live vector map on the left and dynamic event feed cards on the right.
- **Mobile View**: Bottom-sheet pull drawer with touch gestures enabling full-map expansion or card scrolling.
- **Empty & Loading States**: Clean skeletal loader states with pulsating radar rings during initial GPS location lock.

## 04 — The Build

We chose Next.js 14 App Router paired with Firebase GeoFirestore listeners to stream location updates directly to client state with sub-100ms latency.

> *"We chose Firebase for Grabify's spatial storage because GeoHash query listeners allowed real-time updates without polling overhead."*

- **Frontend**: Next.js 14, Tailwind CSS, Framer Motion
- **Database & Auth**: Firebase Firestore & GeoFirestore
- **Deployment**: Vercel Edge Serverless Functions

## 05 — The Result

Grabify was awarded **Runner-up at the VISIO Spark Hackathon 2025**, recognized for exceptional UI responsiveness and spatial performance under live testing conditions.
